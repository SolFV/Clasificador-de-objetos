# Regla de Actualización de Repositorio Git

Cuando el usuario solicite actualizar, sincronizar o subir el repositorio ("actualiza mi repo", "sube los cambios", etc.):
1. Realizar la preparación, edición y limpieza de archivos requerida localmente.
2. Integrar los cambios mediante commit y rebase/merge con la rama remota (`origin/main`).
3. Ejecutar SIEMPRE `git push origin main` de manera automática para publicar y reflejar los cambios directamente en GitHub.
